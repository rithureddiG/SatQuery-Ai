# Benchmarks

VRSBench evaluates single-image captioning, grounding, and VQA. RSVQA evaluates remote-sensing VQA. CDVQA evaluates bi-temporal semantic change VQA. These datasets are evaluation resources, not an undifferentiated training pool.

The current benchmark manifest is `NOT_READY` because no verified benchmark data, split checksums, model checkpoint hashes, or scores are installed. No synthetic integration output is a benchmark score. Blind evaluation labels must be inaccessible to training, threshold tuning, and prompt tuning.
